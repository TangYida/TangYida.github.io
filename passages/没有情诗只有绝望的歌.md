# 没有情诗只有绝望的歌
## （或：总要为这个虚无的午后留下点什么）
我很久没有写诗了，因为没有需求。过去一个月，陆陆续续写了一些无病呻吟的诗。这组诗的标题是随便取的，诗歌内容也是随便写的。倘若它们真的被人看到了并能博君一粲，也就脱了这个“绝望”的名号了。

### 一 泥沙入河
```
要为这个虚无的午后留下
一颗时间的沙粒
于是我留下了对她的爱
她留下了对我的爱
和午后的阳光与静谧一起
刻在一粒沙里

把沙粒抛入时间之河
……船儿顺流 河水早把它埋在河床之下
```

### 二 君自故乡来
```
你从故乡来
应该知道故乡的花期
雨季 回荡在红房子的钟声

乘上了我曾天天仰望的航班
你到这里去
讯息 故乡落在我的身旁

我什么都没有带走
故乡该生长的生长
我什么都没有遗下
除了亲人、爱人还有希望
```

### 三 雨是回忆落地的声音
（此诗思路混乱，请无视）
```
雨落在秋里
雨是一个季节的来临
你是伴着雷声而来的秋季
不 秋季以你命名
我想牵住你的手
让雨把故乡打落
我看见你 你落在秋里

雨落在梦里
雨是回忆落地的声音
雨越下越大
给我带来一切的幽暗和忧伤
我依然想牵住你的手
尽管夏天曾让我签订一个诺言
我画着你 你落在梦里
```

### 四 冬日之门
```
秋风一来
桂花就开
秋虫就会鸣叫
冬天就会钻进棉被里来
如果有壁炉 便可以把火升起
温暖一年的颠沛与寒意

身边的她
——她有寒冷季节的所有花香
桂花、腊梅和雪——
会无声地告诉你
不要再前往别处了
拥有这个夜晚我们就拥有了一切

过去的一年
——呼啸奔腾的风
月亮、书和炉火——
都是我们的
不要再寻觅水和酒了
拥有这个夜晚我们就拥有了
一切

你在哪
还没有叩开冬日的门
我就已经在流浪中
疲惫地沉睡
```
