# 诗三首

### 木叶下
```
秋晨，秋晨华美而无上，
沿着喧哗的林荫道
我们走到这里，
这里沉默的寒色斑驳又旷远，
这里的草地上有鸟飞翔。

从来不知道太阳可以熄灭我们的双眼，
晨雾可以笼罩万物。
参辰啊，是古人种在夜空边的那片藤萝，
我们现在怎么看不清了？

风一吹，
万木零落。
一个巴掌大的金秋
落在我肩头。

不会是分别的时候到了吧，
不会是坠落的时候到了吧。
```

### 游行

```
她的那双眼属于一个疲倦的永夜
她的那头发属于一个没有梳子的春天
牵住两只手 就像戴上一副手铐
忘记她的嘴 就像离开我的房间
她就像上街游行一样
让人魅惑
你问我为什么在长冬怀念着春天
因为我们的青春
还有一场刺激没有完成
```

### 我
```
今天早上我想冲出家门
不过是怕被他们遗弃
我用来指向黑色的利剑
不过是一把开门的钥匙
我想为旗子唱的那首歌
最后因为主旨不清卡在我的喉头

夜深了，你们怎么还是这么吵
都安静下来
诗人要写诗了
乐手要奏乐了
漂泊的人 要入梦了
```
