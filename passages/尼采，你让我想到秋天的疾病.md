# 尼采，你让我想到秋天的疾病
```
尼采你差点让我患上了秋天的疾病
这断然是我这种虚弱的身体所不能承受的
曾把它好好掩盖在楔形文字之下 像个秘密
现在你出生了 患病了 死亡了

是第一次么？
你是秋日草原上的牧人
看上去却这么像个逃犯
在小房子里 你谱好了曲 作好了词
然后指挥自己的悲剧合唱队
对着镜子，演员和观众就可以是一个人
所以你是牧人还是逃犯呢？
是演员还是旁观者？
你始终孤独一人呢还是
你却说——就让我们在黑色大理石上放一把火 烧吧！！！
我抖抖身子 
——甩落了的音乐竟是历史碰撞的声音
尼采 这莫非又是你的反讽？
我给自己点着了一场病 烧吧！

疾病 死亡和生命
我的阿里安她在哪里？

最后一次
我们走到城市的街道
那里的秋日秩序井然
这是第一次啊
亲吻每一个路过的人
告诉他们你对他们的爱
我们歌唱
来歌唱
来歌唱
让我们歌唱吧
让我们舞吧

```
