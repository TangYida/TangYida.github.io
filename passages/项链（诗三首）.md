# 项链（组诗）

## 对月咏怀

```
对月咏怀 多么古典的一个说法
而我们既没有对月，也没有咏怀
古典总是让人困倦
你和我只是走在三月十五的凉风里
想着这一天很特殊
一年只有一次

这一天的月亮挂在天上
就像珍珠挂在你脖子上
而词语是一个脏兮兮的帆布袋
永远也兜不住
又洁白又丰盈的月光
所以，能亲口告诉你的就不要写成诗
能永远铭记的就不要告诉你

我们从哪里来？
我们到哪里去？
你也已经遗忘了吧
在一百年只有一次的那天
我们只是稀里糊涂地在桥上相遇
在分别之后，各自死去
```

## 项链

```
我们像这样
拥抱了多久
对面的墙壁
从紫色变成蓝色
从蓝色变成白色
在港口的船也许早就
起航
把我们落在这里
继续拥抱
可即使鸟儿已经开始鸣叫了
我还是算不清楚
我们拥抱了多久

这个早晨
就像你脖子上的项链的
那颗珍珠
```

## 味道

```
夏天之后
我的面庞
会像秋天的树皮一样粗糙

夏天之前
我却大概率
没有醒来

可夏天是这么地短暂
汽车在柏油路上驶过
呼啸声
热浪
和尾气
去年的落叶又落下了
它就结束了

青春
```
