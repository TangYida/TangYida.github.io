# 诗稿拾遗:过去一年
> 注：过去一年，是指2020年4月-2021年4月这一段时间。他们的存在似乎毫无意义（除了一两句之外），按照时间顺序编排放在这里主要是用以记录过去的生活吧。

一年，好快。每一年里，我们贴着一年四季行走;因而生命的节奏也与春夏秋冬有了几分类似。生命本来贴近大自然的本质，这无疑让生活的感受者和歌唱者感到快慰和感激。但时间的流驶往往不舍昼夜而让人来不及歌唱，面对时间和大河我感到无限愧怍。但所幸的是两点:其一是我终又可以张开手臂迎接新的春天、新的一年;其二是过去好歹还是留下了一些“尚处于试验阶段”的草稿。仅这两点，就足够安慰人了。

## 春天
```
春天不期而至:
她穿着一身浅绿的树叶，
头发上开满明丽的蔷薇。
湖水中明月升起，
在她望向我的眼睛里。
```
## 向山行
```
我载着自己驶向远处群山
那片伤心的黛色
我唯一的藏身之处 
候在窗边的我的暮色群山
```

## 观《阿飞正传》有感
```
穿过这片灰绿色的森林
从此我被流放
像一只飞鸟一样的
从恋人身边流放

这片失落的灰绿色 热带森林
我像一辆破旧的绿皮火车 匆匆穿过
奏着一路破碎的圆舞曲 摇摇晃晃
啊 绿的空气里全是酒
窗户外的摇曳的森林在雨里 说不尽他热带的伤心
那就喝醉吧 抱着自己还有缄默的树 起舞 起舞

我被流放至此
我藉此为乐
我死过一次
```

## 断想·黔水行
```
我们第一次在河水上行船，
开辟鸿蒙之后，为什么在这里我们，
你问。

曾经我一个人在摇晃的船头遥想摇晃着的星辰。
那时，仰阿莎她还没有出生。
我们的摇晃小船还没有载负历史的累，那时，
蛇第一次凫水而至，
送来星星做成你的银饰，美丽的、沉甸甸的银饰。

我的嘴唇第一次亲吻你的银饰，
你的银饰第一次轻吻我的嘴唇，
黔水之上，我的嘴唇再也拔不下来。
```

## 时间之内
```
苍凉暮色把我
染得像雨水中微颤的黄树叶也罢
我才不得已立于深秋 闭目远眺
时间啊时间
我曾顺着春天大道
阳光温柔 绿木覆盖
在音乐流淌着向前的地方
原来那是我见过最美的微笑
时间啊
```
## 时间之外(运动会有感)
```
而这座桥
正对着旭阳的方向
飞越大河后驰往
染上天光的柏油大道

这座城 在路旁暂时沉默
淡蓝色的巨大身影
抬头望着头顶的旭阳

再看看路牌上行将原来远离的星体
现在和肌肤的色彩一样
这个时候，他是
所有、所有通向的地方

此时——
后羿将掷起的响矢
带着沉重的引力飞向弧线顶点
伏羲和女娲一男一女
追逐着奔向远方的远方

而为什么我的眼眶下却
垂悬着薄暮的颜色 且为时间所累呢

而每天这座桥
正对着旭阳的方向
越过大河后驰往······
连接着天光······
```

## 古诗新编·鸷鸟
```
那只终于飞到天边的鸷鸟
终于摆脱悲伤与离群的运命
东皇的太阳升起在
他洁白丰满的羽毛
父辈众神的仙乐在
他谛听许久的耳畔齐响

尘雾中悲伤而热烈的一瞥
是他和乡土一生的命运
怎么也逃不掉

和荆楚大地最后的撞击
是我最盛大的见面礼
再也飞不起来了
溺死在绿油油的水里，水汹涌地东流
——那落水姿势如同
蜷缩在母亲腹里一般
 ```

## 在图书馆读昌耀诗
```
刚刚掩上的黑色门，
那后面隐藏的俄日朵雪峰，高高，
金光闪闪，雪风飘扬。
当白雪雕刻的黑陨石/寂寂地坠下山谷了，
顷刻，
叩问青铜与绿树的声音也荡漾。
```

## 记前几天气温骤暖
```
我与春天擦肩而过，
我伸手，
如何也留他不住。

告诉她新的日子终将开始，
便以为温暖的春天空气飘满黄叶是一种幸福，
独自一人用黄叶编制王冠，抚慰寂寞。

却等来飘满黄叶的秋山被春风惊绿，
我伸手，
不只是迎是拒，
我和春天打了个照面。
```

## 古诗新编·潜行
```
“少陵野老吞声哭，
春日潜行曲江曲。”
所以我泛舟江上，舀饮江水;
他们酿一江春酒，把我醉得一塌糊涂。
星河泛上酒绿，我美好的梦覆压星河上;
梦里一个身影坠入水中，宛若一只忘情的鸟。
```
