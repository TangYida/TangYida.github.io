# 项链（组诗）

## 1. 项链

```
我们像这样
拥抱了多久
对面的墙壁
从紫色变成蓝色
从蓝色变成白色
港口的船也许早就
起航
把我们落在这里
一直拥抱
就好像在我回忆中
挂在你唇边的
那颗晨露
一直没有干涸
它就像挂在你项链上的
那颗珍珠
可在我们将要忘掉时间的时刻
鸟儿却如同汽笛开始鸣叫
```

## 2. 味道

```
夏天之后
我的面庞
会像秋天的树皮一样粗糙

夏天之前
我却大概率
没有醒来

可夏天是这么地短暂
汽车在柏油路上驶过
呼啸声
热浪
和尾气
去年的落叶又落下了
它就结束了

青春
```

## 3. 咏怀

```
对月咏怀 多么古典的一个说法
而我们既没有对月，也没有咏怀
古典总是让人困倦
你和我只是走在三月十五的凉风里
想着这一天很特殊
一年只有一次
这一天的月亮挂在天上
就像珍珠挂在你脖子上

从不咏怀
因为词语是一个脏兮兮的帆布袋
永远也兜不住
又洁白又丰盈的月光
能亲口告诉你的就不要写成诗
能永远铭记的就不要告诉你

从不咏怀
所以，在月亮看来
一百年只有一次的那一天
不过是两个人
稀里糊涂地在桥上相遇
分别之后，各自死去
```

## 4. 沉默

```
沉默
就像夏天的长岛
岸边的炎热气候
只能够听到虫鸣
一百年前我们就是听着这种虫鸣
热死 饿死 累死 孤独地死
你是比虫儿更小的一只小丑
趴在树叶上鸣叫
只要有声音 你就叫喊出来
就算没人听到你的爱
你的痛苦 你的挣扎
就算你的周围空无一人
只有一百年的孤寂
```

## 5. 可是，我的爱人啊

```
一开始，我就对你说
我的爱是廉价的爱
它的价值等价于
一些含糊不清的话
一次违背道德的拥抱
还有一个搞笑的吻
可是为了支付
甚至是预支我的爱
我已经花光了所有的力气
多希望请你听听
我的心跳，依然为你跳动
被关在我孱弱、疲惫的身躯里
请你听听
我不仅爱你的乳房
还爱你的伤疤
所以，我期待爱的时间超过一次相遇
却恐惧它在我们死亡前
衰老、庸俗、夭折
于是我呜呜鸣叫着退缩

可是，我的爱人啊
没有你的时候
我就像一只没有毛的狗
没有人愿意抚摸
```

## 6. 珍珠

```
我一切的悲伤
都是因为缺乏了你的悲伤
我一切的欢乐都是因为
我拾得遗失在过去的珍珠
曾经 我们相互拥抱
我们在土地上相爱
我们在词语的河流里沐浴 亲吻
我甚至想和你、还有时间一起
凝固在那里
我甚至忘记我们是站着的
像快要被收割的麦子一样，插在土地上
```

## 7. 「」

```
我们给世界上所有的词语
都斟满了液体，于是
我们不得不用上了
最后一个杯子
「我爱你」

本来，我们还可以
拥抱，亲吻和做爱
但我们不能一直那样
因为让人窝在家里的雨天
千载难逢

但你不用叹息
你使用最后一个词语时的无助
总让我想起身体疲惫的时候
让我想起大地等不到雨水的时候
```

## 8. My Weekend Lover

```
My weekend lover,
你在我匀速流淌的时间中
搅动出一个漩涡
明天依然不是周末
门在空中划出一道弧
依然不是你
为什么我爱你越深
越感到寂寞
就像孤独的神庙的柱子
等待着下一个雨水充沛的夏天
等候着下一次神谕降临的庆典
```

## 9. 明天一早，你就要去远方劳作

```
明天一早，你就要去远方劳作
沉甸甸的行囊再也塞不下昨夜
我们蒸好的白花花的馒头
你总是喜欢带走火塘里的
最后一点火苗
等我醒来时
一天还剩下半天
窗边只剩下白雾
这天地间剩下凉意
平原上飞起飞落的麻雀
```

## 10. 早晨

```
每天早上起来都要面对一个
蓝绿色的清晨
自从失去了你，亲爱的
我的胸腔就空落落的
如同上午空旷的浴室
如同还没装上那扇充满水雾的玻璃的
水泥房
冬风一过
它就呼呼作响
什么时候才能和这份空洞和解啊
什么时候我才不再去寻找
那个白昼之后的抚慰人疲惫的斜阳
因为我们总是在吊塔上孤独地劳作
却还没有忘记不合时宜的
关于早晨的回忆
```
